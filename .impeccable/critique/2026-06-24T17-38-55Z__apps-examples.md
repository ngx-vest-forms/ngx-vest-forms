## Anti-Patterns Verdict

The overall aesthetic is well-anchored — this does not read as AI slop on first look. However, every demo page opens with the same 2-card identical grid structure. This is the Identical Card Grid anti-pattern applied uniformly across 17 demos. The uppercase tracked sub-headings inside "What you'll learn" cards (e.g., "THE CANONICAL WIRING", "ERRORS BLOCK, WARNINGS ADVISE") are the eyebrow pattern inside card content — decoration rather than navigation.

Detector: 1 finding — `text-gray-400` default on `.business-hours-remove-btn` is ~2.77:1 against white, failing WCAG AA.

## Priority Issues

**[P1] Form always below fold — info cards dominate every page**
All 17 demos begin with the same 2-card explanatory grid before the form. The form (the library's primary value demonstration) requires a scroll on every page.
Fix: Invert layout, make cards collapsible, or reduce visual weight of info cards.
Command: $impeccable shape demo-page-layout

**[P1] Subtitle has no max-width — exceeds 65–75ch prose limit**
The description under each h1 runs full content-area width, producing 100+ char lines.
Fix: Add max-w-[65ch] or max-w-2xl to the subtitle p in ngx-page-title.
Command: $impeccable layout apps/examples/src/app/ui/page-title

**[P2] Uppercase tracked eyebrow subheadings inside "What you'll learn" cards**
Sub-section headers like "THE CANONICAL WIRING" reuse the nav micro style inside card content — violating the Micro Rule in DESIGN.md.
Fix: Replace with bold inline heading at font-semibold text-sm, no uppercase/tracking.
Command: $impeccable typeset apps/examples/src/app/ui/example-cards

**[P2] .business-hours-remove-btn default text-gray-400 fails contrast (2.77:1)**
Resting state fails WCAG AA. Hover state fixes it, but a form library demo must model accessible defaults.
Fix: Change default to text-gray-500 or text-gray-600.
Command: $impeccable audit apps/examples/src/styles.scss

**[P3] Page title is "Examples" on every page — tab titles are useless**
No per-route title set. Every open tab shows "Examples" regardless of which demo is loaded.
Fix: Use Angular Title service per route, keyed from routes.metadata.ts title field.
Command: $impeccable harden apps/examples

## Persona Red Flags
