Zod describes the shape. The Zod schema is the Form Contract. In development it checks the Form Model's structure and logs a warning for a mismatch. It never changes whether a field is valid. Vest owns the rules. Required fields, the email format and the age range 18 to 120 live in the Suite, because only the Suite produces Errors. A rule written in Zod would reach the console, not the field. The schema also marks every field optional, because the Form Model is partial while the user types. Full vs. focused runs. suite.run(model) validates everything; suite.only(field).run(model) runs only that field's tests. Schema inside the Suite. To validate shape in the Suite itself, pass enforce.shape(...) as the second argument of create(). The Native Vest Schema demo shows that.
